## Included

- Independent Codefly service topology, health endpoint, release identifier, and deployment targets.
- Repository Markdown provider with strict front matter and publication metadata.
- Public plan projection with an honest unavailable state.
- Canonical metadata, sitemap, robots policy, feed, security headers, and cache policy.
- Safe product handoff that preserves only approved attribution fields.

## Deliberate boundaries

The release does not create a second waitlist, notification engine, analytics taxonomy, billing state machine, support inbox, or incident system.
